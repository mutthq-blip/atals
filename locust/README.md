# أطلس الجراد الصحراوي

أطلس تفاعلي ثلاثي الأبعاد من وقاء، مبني على «الدليل الإجرائي لاستكشاف ومكافحة الجراد الصحراوي» (WEQAA-600.4-M-001 · V02-05/26).

الرابط: https://mutthq-blip.github.io/atals/locust/

## الأقسام
الجرادة · دورة الحياة · المظهران · مواسم التكاثر · الأضرار · الرصد والمسح · المكافحة · اختبر نفسك،
مع اختبار قبلي وبعدي (5 أسئلة)، وتعليق صوتي بصوت الجهاز، ووضع المعرض (`#expo`)، وصندوق «شفت جراد؟ بلّغ وقاء».

## البناء
عدّل ملفات `locust/src/` ثم:

```bash
python3 locust/assemble.py
```

يكتب `locust/index.html` (ملف واحد يعمل دون إنترنت، وهو المنشور على GitHub Pages) و`locust/dev.html` للتطوير (يحمّل three.js والخط من CDN).

## الأحداث للموقع المستضيف
مثل أطلس السوسة، يرسل الأطلس `postMessage` إلى الصفحة الأم مع `atlas:'locust'`:
`weqaa-atlas-assessment` (القبلي والبعدي)، `weqaa-atlas-view` (فتح قسم)، `weqaa-atlas-report` (الضغط على البلاغ).
