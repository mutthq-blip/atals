# أطلس سوسة النخيل الحمراء

تصوّر لعرض أطلس سوسة النخيل الحمراء على موقع وقاء: الصفحة الرئيسية فيها الأطالس جنب بعض (سوسة النخيل الحمراء، حافرة الطماطم، والجراد الصحراوي قريباً)، ومن أطلس السوسة تنتقل لداشبورد قياس الأثر.

الرابط: https://mutthq-blip.github.io/atals/

روابط مباشرة: #atlas (سوسة النخيل)، #tomato (حافرة الطماطم)، #dashboard (الداشبورد).

الملفات: index.html الرئيسية، palm/ أطلس السوسة، tomato/ أطلس الطماطم، dashboard/ الداشبورد، og.jpg صورة المشاركة.

أرقام الداشبورد تجريبية لين يبدأ موقع وقاء يستقبل النتائج.
